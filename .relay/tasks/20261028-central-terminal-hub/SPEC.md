# เอกสารกำหนดความต้องการ (SPEC.md) — ขั้นตอนที่ 1 (`@po`)
- **รหัสใบงาน:** `20261028-central-terminal-hub`
- **ชื่อใบงาน:** ระบบหน้าจอ Terminal กลาง (`relay` Central Terminal Hub) และการตั้งค่าจับคู่บทบาทตัวแทน AI กับค่ายผู้ให้บริการ (`Role-to-Provider Mapping`)
- **สถานะ:** ยืนยันข้อกำหนดจากผู้ใช้ครบถ้วนแล้ว

## 1. วัตถุประสงค์ (Objective)
พัฒนาโปรแกรมควบคุมผ่านหน้าจอ Terminal กลาง (คำสั่ง `relay`) เพื่อให้ผู้ใช้งานสามารถควบคุมกระบวนการทำงานทั้ง 4 ขั้นตอน (`@po`, `@arch/@pm`, `@dev`, `@qa/@sec`) ได้จากหน้าต่าง Terminal เดียวโดยไม่ต้องพิมพ์สลับโปรแกรมไปมาด้วยตนเอง พร้อมระบบตั้งค่ากำหนดว่าแต่ละตำแหน่งจะเรียกใช้ CLI ของค่ายใด (`claude`, `codex`, หรือ `gemini`)

## 2. ข้อกำหนดที่ตกลงร่วมกัน (Confirmed Requirements)
1. **การตั้งค่าจับคู่บทบาทกับค่ายผู้ให้บริการ AI (`Role-to-Provider Mapping`):**
   - มีไฟล์ตั้งค่าระดับส่วนกลางของเครื่อง `~/.agents/relay-roles.conf` (หรือ `%USERPROFILE%\.agents\relay-roles.conf` บน Windows) สำหรับกำหนดค่าเริ่มต้นของทุกโครงการ
   - รองรับการตั้งค่าแยกเฉพาะโครงการที่ไฟล์ `.relay/roles.conf` หากโครงการใดต้องการเปลี่ยนค่าย AI เฉพาะกิจ
   - ผู้ใช้สามารถเปลี่ยนค่าย AI ของแต่ละตำแหน่ง (`@po`, `@arch/@pm`, `@dev`, `@qa/@sec`) ได้ตลอดเวลาผ่านเมนู `[c]` ในหน้าจอกลาง หรือคำสั่ง `relay config`
2. **หน้าจอควบคุมส่วนกลางใน Terminal เดียว (`relay` Central Terminal Hub):**
   - พิมพ์คำสั่ง `relay` ในโฟลเดอร์โครงการเพื่อเปิดหน้าจอควบคุมแบบ Interactive Menu (และรองรับคำสั่งทางลัด เช่น `relay 1`, `relay 2`, `relay 3`, `relay 4`, `relay config`, `relay init`)
   - แสดงชื่อโครงการ สถานะใบงานปัจจุบัน (`SPEC.md`, `ARCH.md`, `PLAN.md`, `QA_REPORT.md`) และค่าย AI ที่ผูกไว้กับแต่ละขั้นตอน
   - เมื่อเลือกขั้นตอนที่ 1–4 ตัวโปรแกรม `relay` จะเรียกใช้งาน CLI ของค่ายที่ตั้งค่าไว้ขึ้นมาทำงานในหน้าต่าง Terminal เดิมทันที พร้อมส่งคำสั่งเริ่มต้นที่อ้างอิงไฟล์ใน `.relay/tasks/<task-id>/` ให้โดยอัตโนมัติ และเมื่อพิมพ์ `/exit` ออกจาก CLI ของขั้นนั้น จะกลับคืนสู่หน้าจอเมนูกลางของ `relay` ทันที
   - ในขั้นตอนที่ 3 (`@dev`) ระบบจะสร้างและสลับเข้าสู่สภาพแวดล้อมการทำงานแยกอิสระ (`Git Worktree` ที่ `.relay/worktrees/<task-id>` บนกิ่ง `feat/<task-id>`) ให้อัตโนมัติ
   - มีเมนู `[5]` สำหรับตรวจสอบ `git diff`, ผสานโค้ดเข้าสู่กิ่ง `main`, ลบ Worktree ชั่วคราว และย้ายใบงานเข้าสู่ `.relay/archive/` ในขั้นตอนเดียว
