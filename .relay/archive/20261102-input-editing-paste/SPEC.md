# ใบงาน: ช่องพิมพ์ข้อความของ RELAY ใช้ลูกศรแก้ไขได้ และวางข้อความหลายบรรทัดได้ (20261102-input-editing-paste)
- **ปัญหา:** ช่องพิมพ์ทุกจุดใช้ `read -r -p` ธรรมดา (bash 3.2 บน macOS) ➔ กดลูกศรได้ `^[[D` แก้คำกลางประโยคไม่ได้ • วางข้อความหลายบรรทัด (เช่น คำอธิบายให้ @po) ได้แค่บรรทัดแรก บรรทัดที่เหลือไหลไปตอบเมนู/ช่องถัดไป

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- [ ] มีฟังก์ชันกลาง `relay_read_input <ตัวแปร> <ข้อความถาม>` ใช้แทน `read -r -p` ของช่องพิมพ์ข้อความทุกจุด (ไม่รวม "กด Enter เพื่อ…") และช่อง `/` พิมพ์เมนู
- [ ] บน Terminal: ใช้ readline ➔ ลูกศรซ้าย/ขวา, Home/End, Backspace แก้ข้อความได้ รวมภาษาไทยที่มีสระบน/ล่าง
- [ ] วางข้อความหลายบรรทัด (ทั้งแบบ CR/LF และไม่มี Enter ปิดท้าย) ➔ ได้เป็นคำตอบเดียวของช่องนั้น ไม่ไหลไปตอบช่องถัดไป
- [ ] ไม่ใช่ Terminal (pipe/เทสต์) ➔ ทำงานเหมือนเดิม
- [ ] เทสต์ผ่าน pty จำลอง และชุดทดสอบทั้งหมดผ่าน
