# ใบงาน: กฎคุณภาพโค้ดสำหรับ @dev และ @qa ใช้ได้ทุกภาษา (20261102-code-quality-rules)
- **ปัญหา:** ยังไม่มีคำสั่งให้ AI ใช้โค้ดเดิมซ้ำ ห้ามโค้ดซ้ำ หรือยึดแบบแผนเดิมของโปรเจกต์ • `@qa` ให้ PASS ได้แม้โค้ดซ้ำ ถ้าเทสต์ผ่าน
- **ข้อจำกัด:** กฎสั้น ไม่ผูกกับภาษาใด • ไม่เพิ่มไฟล์เอกสาร ไม่เพิ่มขั้นตอน และไม่เพิ่มการเรียก AI

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- [ ] prompt ของ `@dev` (ขั้นที่ 3, งานด่วน, ลูปอัตโนมัติ) มีกฎ: อ่านโค้ดที่เกี่ยวข้องและยึดแบบแผนเดิม • ค้นของเดิมก่อนสร้างใหม่ ห้ามคัดลอกโค้ดมาแก้ • แยกเป็นของกลางเมื่อใช้ซ้ำจริงอย่างน้อย 2 จุด ไม่สร้าง abstraction เผื่อไว้ • แก้เท่าที่งานต้องการ
- [ ] สัญญาผลตรวจของ `@qa` ตรวจ diff เรื่องโค้ดซ้ำ ไม่ใช้ของเดิมที่มีอยู่ และผิดแบบแผน ➔ ใส่ใน failed_criteria พร้อม file:line
- [ ] `templates/relay-roles-SKILL.md` (ใช้ตอนเรียกบทบาทเองใน CLI) มีกฎเดียวกัน
- [ ] มีเทสต์ตรวจว่ากฎอยู่ใน prompt จริง และชุดทดสอบเดิมผ่านทั้งหมด
