# ปรับปรุงคำสั่ง Prompt ประจำตำแหน่งให้ชัดเจน ไม่ขัดแย้งกัน และลดภาระ Token (`20261030-prompt-alignment-and-clarity`)

## 1. เป้าหมาย (Objective)
แก้ไขความขัดแย้งระหว่าง `templates/GLOBAL_AGENTS.md` และคำสั่ง Prompt ใน `relay.sh` ทั้ง 5 จุด เพื่อให้ตัวแทน AI ทั้ง 4 ตำแหน่ง (`@po`, `@arch`, `@dev`, `@qa`) ทำงานสอดคล้องกันทั้งในโหมดปกติ โหมด `Fast Track` และ `Auto-Relay Loop`

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
- [ ] AC-1: กฎข้อ 5 ใน `GLOBAL_AGENTS.md` ระบุชัดเจนว่าในใบงานปกติ ห้าม AI แก้ไข `.relay/PROJECT_STATE.md` หรือย้ายโฟลเดอร์เข้า `.relay/archive/` เอง (เป็นหน้าที่ของขั้นตอนที่ 5 Merge)
- [ ] AC-2: Prompt ของ `@po` อนุญาตให้สรุป `SPEC.md` (≤40 บรรทัด) ได้ทันทีหากโจทย์ชัดเจน หรือถามรวบยอดไม่เกิน 3 ข้อหากมีจุดคลุมเครือ
- [ ] AC-3: Prompt ของ `@arch` แยกขอบเขต `ARCH.md` (≤30 บรรทัด: โครงสร้างและไฟล์ที่แก้) กับ `PLAN.md` (≤30 บรรทัด: ขั้นตอนลงมือทำและคำสั่งเทสต์ ห้ามเขียนซ้ำ)
- [ ] AC-4: กฎของ `@dev` รองรับทั้งโหมดปกติ (`SPEC`+`ARCH`+`PLAN`), โหมด `Fast Track` (มีเฉพาะ `SPEC`), และรอบแก้บั๊ก (`QA_REPORT`+`QA_VERDICT.json`)
- [ ] AC-5: Prompt ของ `@qa` ในโหมดกดมือ (`run_phase_4_qa`) และโหมดอัตโนมัติ (`run_auto_relay_loop`) ใช้โครงสร้างคำสั่งเดียวกันและผ่านชุดทดสอบ `tests/test_*.sh` ครบทุกข้อ
