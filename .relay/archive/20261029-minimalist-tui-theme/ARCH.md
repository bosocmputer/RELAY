# เอกสารสถาปัตยกรรมระบบ (ARCH.md) — ขั้นตอนที่ 2 (`@arch`)
- **รหัสใบงาน:** `20261029-minimalist-tui-theme`

## 1. โครงสร้างชุดสี Minimalist High-Contrast (ANSI Standard 16/256)
- `C_RESET=$'\033[0m'` (ใช้สี Foreground เริ่มต้นของ Terminal เสมอ — ดำบนพื้นขาว / ขาวบนพื้นดำ)
- `C_BOLD=$'\033[1m'` (ตัวหนาสีมาตรฐานของ Terminal)
- `C_MUTED=$'\033[38;5;242m'` (สีเทาเข้มปานกลางที่อ่านชัดทั้งบนพื้นขาวและพื้นดำ)
- `C_ACCENT=$'\033[38;5;26m'` (สีน้ำเงินครามเข้ม Royal/Cyan Blue คมชัดทั้งบนพื้นขาวและพื้นดำ)
- `C_SEL=$'\033[1;38;5;26m\033[4m'` หรือ `\033[1;36m` (สีฟ้าครามตัวหนาสำหรับบรรทัดที่เลือก `❯` คลุมทั้งประโยค)
- `C_OK=$'\033[38;5;28m'` (สีเขียวเข้มมรกต อ่านชัดบนพื้นขาวและพื้นดำ)
- `C_WARN=$'\033[38;5;166m'` (สีส้มเข้ม Amber อ่านชัดบนพื้นขาวและพื้นดำ)
- `C_ERR=$'\033[38;5;160m'` (สีแดงเข้ม Crimson อ่านชัดบนพื้นขาวและพื้นดำ)

## 2. กลไกการวาดรายการเมนู (`interactive_menu`)
- ยกเลิกการแยกข้อความ `colored_lbl` กับ `plain_lbl` ที่ทำให้ข้อความสั้นยาวไม่เท่ากัน
- ส่งรูปแบบ `"คีย์|ข้อความเดียว"` เท่านั้น:
  - **เมื่อไม่ได้เลือก:** `    [คีย์] ข้อความ` (คีย์เป็นสี `C_ACCENT`, ข้อความเป็นสีปกติของ Terminal `C_RESET`)
  - **เมื่อเลื่อนลูกศรมาเลือก (`i == selected`):** `  ❯ [คีย์] ข้อความ` (ทั้งบรรทัดตั้งแต่ `❯` จนจบตัวอักษรสุดท้ายเป็น `${C_SEL}` สีฟ้าครามเข้มตัวหนาครบทุกตัวอักษร 100%)
