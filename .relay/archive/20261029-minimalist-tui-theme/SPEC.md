# เอกสารกำหนดความต้องการ (SPEC.md) — ขั้นตอนที่ 1 (`@po`)
- **รหัสใบงาน:** `20261029-minimalist-tui-theme`
- **ชื่อใบงาน:** ปรับปรุงธีมสี `RELAY Central Terminal Hub` เป็นสไตล์ Minimalist High-Contrast และแก้ไขการไฮไลต์บรรทัดที่เลือก (`❯`) ให้คลุมครบ 100% ทุกตัวอักษร
- **สถานะ:** ยืนยันข้อกำหนดจากผู้ใช้ครบถ้วนแล้ว (`สไตล์ที่ 1`)

## 1. วัตถุประสงค์ (Objective)
แก้ไขปัญหาการใช้สีรุ้งมากเกินไปจนลายตา และแก้ไขบั๊กการวาดแถบสีพื้นหลังบน macOS Terminal ที่ตัดสระไทยทำให้ข้อความท้ายบรรทัดหลุดออกนอกแถบสีหรือจางหายบนพื้นหลังสีขาว (Light Mode)

## 2. ข้อกำหนดที่ตกลงร่วมกัน (Confirmed Requirements)
1. **ระบบสี 3-Tier Minimalist Palette (รองรับทั้ง Terminal พื้นหลังสีขาวและสีดำ 100%):**
   - **สีข้อความหลัก (Default Terminal Foreground):** ใช้สีมาตรฐานของหน้าต่าง Terminal (`\033[0m` / `\033[1m`) เพื่อให้แสดงเป็นสีดำคมชัดบนพื้นขาว และสีขาวคมชัดบนพื้นดำ (ห้ามใช้สีขาว `255` หรือสีเหลืองอ่อน `220` ที่กลืนกับพื้นขาว)
   - **สีหลักของระบบ (Primary Accent — น้ำเงินคราม `\033[36m` / `\033[1;34m`):** ใช้กับเส้นกรอบ คีย์ลัด `[...]` และบรรทัดที่กำลังเลื่อนลูกศรเลือก (`❯`)
   - **สีบอกสถานะ (Semantic Status เท่านั้น):** ใช้สีเฉพาะสถานะสำคัญ ได้แก่ สีเขียว (`● พร้อมใช้งาน`), สีแดง (`✖ ยังไม่ติดตั้ง / 🔒 ล็อก`), และสีส้มเข้ม (`⚠️ รอเลือกโมเดล`)
2. **การแสดงผลบรรทัดที่กำลังเลือกด้วยลูกศร (`❯` — สไตล์ที่ 1 แบบ Claude Code):**
   - เมื่อเลื่อนลูกศร `↑`/`↓` มาที่รายการใด ให้แสดงลูกศร `❯` นำหน้า และเปลี่ยนข้อความทั้งบรรทัดเป็น **สีน้ำเงินครามตัวหนา (`\033[1;36m`)** โดยใช้ข้อความชุดเดียวกันเป๊ะกับสถานะปกติ เพื่อให้คลุมครบตั้งแต่ตัวอักษรแรกถึงตัวสุดท้าย 100% ไม่มีปัญหาสระไทยแหว่ง
3. **เส้นกรอบแบบ Open-Right (ไม่ปิดเส้นกรอบขวา):**
   - ใช้เส้นกรอบด้านซ้าย `╭──`, `│`, `╰──` โดยไม่มีเส้น `│` ด้านขวาที่เยื้องเมื่อแสดงผลภาษาไทย
4. **แก้ไข `relay-skills.sh` เรื่อง `stdin`:**
   - เพิ่ม `-y < /dev/null` ในคำสั่ง `npx -y skills add ... -g -y < /dev/null` เพื่อป้องกัน `npx` ดูดข้อมูลจากลูป `while read`
