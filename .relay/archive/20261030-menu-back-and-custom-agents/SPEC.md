# เอกสารกำหนดความต้องการ (SPEC — 20261030-menu-back-and-custom-agents)

## 1. เป้าหมาย (Objective)
1. **ปรับปรุงการนำทางย้อนกลับ (`[b] ย้อนกลับ` / ปุ่ม `ESC`) ครบทุกเมนูและจุดรับข้อมูลใน `relay.sh`:**
   - เพิ่มตัวเลือก `[b] ย้อนกลับ (ใช้ค่าเดิม)` ในหน้าเลือก Model (`choose_model_interactive`) และหน้าแจ้งเตือนติดตั้ง/เข้าสู่ระบบใน `choose_provider_interactive`
   - เมื่อเลือก `[b] ย้อนกลับ` ในหน้าเลือกค่าย AI ให้ถอยกลับไปเมนูตั้งค่าทันทีโดยไม่บังคับเปิดหน้าเลือก Model ต่อ และเพิ่มตัวเลือกสลับเฉพาะ Model ได้โดยตรง
   - รองรับการกดปุ่ม `ESC` ใน `interactive_menu` เพื่อย้อนกลับ (`b`) ได้ทุกเมนู และพิมพ์ `b` ในช่องรับข้อความ (`read -r -p`) เพื่อยกเลิกและย้อนกลับได้ทุกจุด
   - ปรับถ้อยคำในเมนูและหัวข้อให้สุภาพ เป็นทางการ และเข้าใจง่าย (ไม่ใช้คำว่า "ศูนย์จัดการ...")
2. **การจัดการบทบาท Agent, คำสั่ง Prompt และทักษะ (`[g]` / `/agents` / `relay agents`):**
   - **ปรับแต่ง 4 ตำแหน่งหลัก (`@po`, `@arch`, `@dev`, `@qa`):** แก้ไขชื่อบทบาท, คำสั่ง Prompt บทบาทหน้าที่เพิ่มเติม, ชุดทักษะ (`Skills`), และค่าย/Model หรือรีเซ็ตกลับเป็นค่าเริ่มต้นได้
   - **เพิ่ม/แก้ไข/ลบ Agent ตำแหน่งใหม่ (เช่น `@ux`, `@devops`, `@data`):** กำหนดรหัส (`@slug`), ชื่อบทบาท, คำสั่ง Prompt บทบาทหน้าที่, เลือกผูกชุดทักษะ (`Skills`), เลือกโฟลเดอร์ทำงาน (`Project Root` หรือ `Git Worktree`), และเลือกค่าย (`agy`/`codex`/`claude`) + Model
   - **ขอบเขตการบันทึก:** สลับบันทึกได้ทั้งระดับ Global (`~/.agents/custom-agents.json`) และเฉพาะโปรเจกต์ (`.relay/custom-agents.json`)
   - **การเรียกใช้งานจริง:** สั่งรัน Agent ตำแหน่งใหม่ได้จากหน้าจอหลัก, แสดงสถานะบน Dashboard, ทดสอบความพร้อมใน `[t]` (`/test`), และวัดเวลา + Token จริงใน `[v]` (`relay stats`)

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
- [ ] AC-1: ทุกเมนูย่อย (รวมถึงหน้าเลือก Model) มี `[b] ย้อนกลับ` รองรับปุ่ม `ESC` และพิมพ์ `b` ในช่องรับข้อความเพื่อย้อนกลับได้โดยไม่เปลี่ยนค่าเดิม
- [ ] AC-2: เมนู `[g]` (`/agents` / `relay agents`) เพิ่ม/แก้ไข/ลบ Agent ตำแหน่งใหม่ และปรับแต่ง Prompt/Skills/Model ของ 4 ตำแหน่งหลักได้ทั้งระดับ Global และ Project ด้วยภาษาที่เป็นทางการและเข้าใจง่าย
- [ ] AC-3: Agent ตำแหน่งใหม่สามารถสั่งรันงานจริง, ทดสอบใน `[t]`, และบันทึกสถิติ Token จริงลง `RUN_LOG.jsonl` (`[v]`) ได้ พร้อมผ่านชุดทดสอบอัตโนมัติครบทุกข้อ
