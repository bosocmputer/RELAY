# ใบงานกฎ "รายงานตามจริง + ไม่เพิ่มพิธีกรรม" ให้ทุกตำแหน่ง AI (20261102-reality-first-rules)
- **ที่มา:** ผู้ใช้ต้องการให้ AI อยู่กับความเป็นจริง • prompt ปัจจุบันมีแค่เพดานบรรทัดและ "ห้ามเกริ่นนำเยิ่นเย้อ" ไม่มีกฎเรื่องอ้างเกินจริง/พิธีกรรม • `[t]` สั่งให้ AI "ยืนยันชุดทักษะ" ทั้งที่ยังไม่ได้เปิดไฟล์ และสรุปผลว่า "พร้อมใช้งานเรียบร้อย" ทั้งที่ตรวจแค่การเชื่อมต่อ
- **ข้อจำกัด:** ใส่กฎที่เดียว (ไม่คัดลอกซ้ำทุก prompt เพื่อไม่เพิ่ม Token), ห้ามเพิ่มขั้นตอนหรือเอกสารบังคับ

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- [ ] `templates/GLOBAL_AGENTS.md` มีกฎ [ใช้กับทุกโครงการ] เรื่องรายงานตามจริง (No Over-claiming) และไม่เพิ่มพิธีกรรม (No Ceremony Overhead) แบบกระชับ
- [ ] สัญญาผลตรวจของ `@qa` ห้ามให้ PASS เมื่อไม่ได้รันเทสต์จริง และ `tests_run` ต้องเป็นคำสั่งที่รันจริงเท่านั้น
- [ ] `[t]` ไม่สั่งให้ AI "ยืนยัน" ทักษะที่ยังไม่ได้ตรวจ และข้อความผลลัพธ์บอกตามจริงว่าตรวจแค่การเชื่อมต่อ
- [ ] ชุดทดสอบทั้งหมดผ่าน 0 ข้อผิดพลาด
