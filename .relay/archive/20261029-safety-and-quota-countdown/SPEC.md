# SPEC — ป้องกันโค้ดหาย + นับถอยหลังโควต้า + หน้าจอกระชับ (20261029-safety-and-quota-countdown)

> ขอบเขต: ตัวเลือก A ที่ผู้ใช้ยืนยันแล้ว (อ้างอิงผลวิเคราะห์ C1, C2, C3, C4, M1, M4, M6)
> นอกขอบเขต: Windows parity ของ `[a]`/`[l]` (C5), Self-Learning ด้วย AI (M2), การตัดข้อความตามความกว้างจอ (M5) — ทำในรอบถัดไป

## 1. ขั้นตอนที่ 5 (Merge & Archive) ต้องไม่ทำให้โค้ดหาย (C1, C2)
- ก่อนผสาน ต้องแสดงสรุป: กิ่งปลายทาง, จำนวน commit ใหม่ในกิ่ง `feat/<task>`, จำนวนไฟล์ที่ยังไม่ commit ใน Worktree (ไม่นับ `.relay/`)
- ถ้ามีไฟล์ค้างไม่ commit ต้องเสนอให้ commit อัตโนมัติ (ไม่รวม `.relay/`) ก่อนผสาน
- ถ้ากิ่งไม่มี commit ใหม่เลย ต้องไม่ลบ Worktree/กิ่ง และแจ้งผู้ใช้
- ใช้ `git merge --no-ff`; ถ้าล้มเหลว (เช่น conflict) ต้อง `git merge --abort`, แจ้งข้อผิดพลาด, **ไม่ลบ Worktree และไม่ย้ายใบงานเข้า archive**
- ถ้ากิ่งปลายทางไม่ใช่ `main`/`master` ต้องถามยืนยันก่อน
- ลบ Worktree ได้เฉพาะหลังผสานสำเร็จและยืนยันแล้วว่าไม่มีไฟล์โค้ดค้าง; สกัดบทเรียนหลังผสานสำเร็จเท่านั้น

## 2. การสร้าง Worktree ต้องไม่ล้มแบบเงียบ (M6)
- ถ้า `git worktree add` ล้มเหลว ต้องแสดงข้อความ error จริงและหยุด (ห้ามทำงานต่อบนกิ่งหลัก)
- เพิ่ม `.relay/worktrees/` ใน `.gitignore` ของโปรเจกต์อัตโนมัติ
- Prompt ของ `@dev` ต้องสั่งให้ commit งานในกิ่ง `feat/<task>` เมื่อเสร็จ (ห้าม commit `.relay/`)

## 3. Auto-Relay Loop ตัดสินผลได้ถูกต้อง (C3, C4)
- นับว่าผ่านเฉพาะเมื่อ `QA_REPORT.md` มี `VERDICT: PASS` อย่างชัดเจน และไม่มี `VERDICT: FAIL`
- ก่อน `@qa` รันแต่ละรอบ ย้ายรายงานเก่าไปเป็น `QA_REPORT.before-round-N.md` เพื่อไม่ให้รายงานเก่าถูกนับซ้ำ
- ถ้า agent คืนค่า error, หมดเวลา, หรือไม่ได้สร้างไฟล์ที่ต้องได้ (`PLAN.md`, `QA_REPORT.md`) ต้องหยุดลูปและบันทึกเหตุผลลง `LOOP_LOG.md`
- เพดานเวลาต่อขั้น ค่าเริ่มต้น 30 นาที (ปรับได้ด้วย `RELAY_STEP_TIMEOUT` หน่วยวินาที)
- โหมดสิทธิ์แบบไม่ต้องถามโต้ตอบ: `agy --mode auto`, `claude --permission-mode acceptEdits`, `codex exec --full-auto` (ไม่ใช้โหมดข้ามสิทธิ์ทั้งหมด)

## 4. นับถอยหลังเวลารีเซ็ตโควต้า + หน้าจอกระชับ (คำขอผู้ใช้, M1, M4)
- แคชโควต้าเก็บเวลารีเซ็ตเป็น epoch (`*_RESET_EPOCH`) และคำนวณนับถอยหลังตอนวาดหน้าจอทุกครั้ง
- รูปแบบ: `อีก Xวัน Yชม.` / `อีก Xชม.YYน.` / `อีก Xน.` ตามด้วยเวลาจริงในวงเล็บ
- ถ้าเลยเวลารีเซ็ตแล้ว แสดง `↻ รีเซ็ตแล้ว` และถือว่าโควต้ารอบนั้นกลับเป็น 100% (ทั้งการแสดงผลและ Quota Circuit Breaker)
- หัวกล่องโควต้าแสดงอายุข้อมูล (`เมื่อสักครู่` / `X นาทีที่แล้ว`) และเตือนเมื่อเก่ากว่า 15 นาที
- จัดโควต้าเป็นตาราง 3 คอลัมน์ (ค่าย / 5 ชั่วโมง / รายสัปดาห์) ที่จัดแนวถูกต้องกับภาษาไทย
- คอลัมน์สถานะของตำแหน่งแสดงแค่ `● พร้อมใช้` หรือ `▲ โควต้าต่ำ X%` (ไม่ซ้ำกับตารางโควต้า)
- หน้า `[u]` / `relay quota` แสดงนับถอยหลังด้วย

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- **AC-1** Worktree มีไฟล์ไม่ commit ➔ ขั้นตอนที่ 5 commit ให้ (ไม่รวม `.relay/`), ผสานเข้า `main` สำเร็จ, ไฟล์อยู่ใน `main`, ใบงานเข้า archive
- **AC-2** Merge conflict ➔ ยกเลิก merge, Worktree และใบงานยังอยู่ครบ, repo ไม่ค้างสถานะ merge
- **AC-3** กิ่งไม่มี commit ใหม่ ➔ ไม่ลบ Worktree/กิ่ง
- **AC-4** Loop: QA รอบ 1 FAIL, รอบ 2 PASS ➔ จบที่รอบ 2, มี `QA_REPORT.before-round-2.md`
- **AC-5** Loop: QA_REPORT ไม่มี VERDICT ➔ ไม่นับว่าผ่าน
- **AC-6** Loop: agent ค้างเกินเวลา ➔ หยุดลูปพร้อมเหตุผลใน `LOOP_LOG.md`
- **AC-7** หน้าจอแสดงนับถอยหลังถูกต้อง, เวลาที่เลยแล้วแสดง `↻ รีเซ็ตแล้ว` และ 100%, คอลัมน์ตารางตรงแนว
- **AC-8** `bash -n relay.sh` ผ่าน
