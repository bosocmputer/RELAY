# ใบงานแก้เมนูวาดซ้อนเมื่อกดลูกศรรัว (20261031-menu-echo-drift)
- **ที่มา:** ทดลองใช้จริงหลังตัดข้อความเมนูแล้ว บรรทัด `[1] @po` ยังซ้ำ 4 ครั้ง • จำลองซ้ำได้: ปุ่มที่กดระหว่างวาดเมนูใหม่ (นอกช่วง `read -s`) ถูก tty echo กลับเป็น `ESC[B` เมื่อ Terminal ไม่ได้เปิด ECHOCTL ทำให้เคอร์เซอร์เลื่อนลงทีละบรรทัด
- **ข้อจำกัด:** `/bin/bash` 3.2, ห้ามทิ้ง tty ในสถานะปิด echo หลังออกจากเมนู / Ctrl+C / ออกโปรแกรม

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- [ ] ระหว่างแสดงเมนู ปิด echo ของ tty ตลอดเวลา และคืนค่าเดิมทุกทางออก (เลือกรายการ, ย้อนกลับ, พิมพ์ `/`, Ctrl+C, ออกโปรแกรม)
- [ ] กดลูกศรรัวจนปุ่มตกช่วงที่กำลังวาดเมนูใหม่ แล้วเมนูไม่ซ้อน และเลือกรายการได้ถูก
- [ ] ชุดทดสอบทั้งหมดผ่าน 0 ข้อผิดพลาด
