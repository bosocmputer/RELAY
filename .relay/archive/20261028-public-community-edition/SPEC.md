## 1. วัตถุประสงค์ (Objective)
ปรับปรุงโครงการ `https://github.com/bosocmputer/RELAY.git` (และโฟลเดอร์หลัก `/Users/nontawatwongnuk/dev_bos/RELAY`) ให้เป็นมาตรฐานการพัฒนาซอฟต์แวร์ด้วย AI แบบหลายตัวแทน (Multi-Agent CLI Workflow) สำหรับสาธารณะ โดยใช้ภาษาทางการระดับวิศวกรรมซอฟต์แวร์ทั้งหมด ลบไฟล์ตัวอย่างที่ไม่จำเป็นออก และเพิ่มคู่มือการติดตั้งและใช้งานตั้งแต่เริ่มต้นสำหรับทั้ง Windows และ macOS

## 2. ข้อกำหนดที่ตกลงร่วมกัน (Confirmed Requirements)
1. **การใช้ภาษาทางการระดับวิศวกรรม (Formal Engineering Terminology):**
   - ปรับปรุงเอกสารและสคริปต์ทั้งหมดให้ใช้ศัพท์เทคนิคมาตรฐาน เช่น ใช้คำว่า **"ขั้นตอนที่ 1–4 (Phase 1–4)"**, **"เอกสารส่งมอบงาน (Handoff Artifacts)"**, **"สภาพแวดล้อมการทำงานแยกอิสระ (Isolated Git Worktree)"**, **"ชุดทักษะเฉพาะทาง (Modular Skill Packs)"**, และ **"กลไกตรวจสอบความปลอดภัยก่อนบันทึกโค้ด (Pre-commit Security Hook)"**
2. **การจัดการโครงสร้างโครงการและเครื่องมือภายนอก:**
   - ลบโฟลเดอร์ `dashboard/` และ `examples/cafe-pos/` ออกทั้งหมด รวมถึงตัดการอ้างอิงเครื่องมือภายนอกที่ไม่จำเป็นออกทั้งหมด โดยใช้คำสั่งมาตรฐานของระบบ `Git Worktree` (`claude --worktree` และ `git worktree`) แทน 100%
3. **การติดตั้งและใช้งานร่วมกับโปรแกรม Obsidian:**
   - อธิบายความสำคัญของโปรแกรม Obsidian ในฐานะระบบจัดการเอกสารโครงการและฐานความรู้ (Project Documentation & Knowledge Management)
   - อธิบายวิธีติดตั้งสำหรับผู้ที่ยังไม่มีโปรแกรม (ทั้งบน Windows และ macOS) และขั้นตอนการเชื่อมต่อโฟลเดอร์ `.relay/` เข้ากับ Obsidian Vault
4. **คู่มือและสคริปต์สำหรับการนำ `RELAY` ไปใช้งานจริง 2 กรณีศึกษา (2 Core Use Cases):**
   - **กรณีศึกษาที่ 1: การเริ่มต้นโครงการใหม่ตั้งแต่ศูนย์ (Greenfield Project)** — การเตรียมโครงสร้าง `RELAY` ก่อนเริ่มพัฒนาซอฟต์แวร์ (Vibe Coding)
   - **กรณีศึกษาที่ 2: การนำ `RELAY` ไปประยุกต์ใช้กับโครงการเดิมที่มีอยู่แล้ว (Brownfield / Existing Project)** — การสร้างโครงสร้าง `.relay/` ในโครงการเดิม และการสั่งให้ AI วิเคราะห์โครงสร้างโค้ดเดิมเพื่อสร้างไฟล์ `.relay/PROJECT_STATE.md` ตั้งต้น
   - มีสคริปต์ช่วยสร้างโครงสร้างอัตโนมัติ (`relay-init.sh` สำหรับ macOS/Linux และ `relay-init.ps1` สำหรับ Windows) ควบคู่กับคำสั่งสร้างด้วยตนเองในคู่มือ
5. **การซิงก์ข้อมูล:** อัปเดตไฟล์กฎกลาง `~/.agents/GLOBAL_AGENTS.md` บนเครื่องของผู้ใช้ ซิงก์เข้าสู่ `/Users/nontawatwongnuk/dev_bos/RELAY` และบันทึกขึ้น GitHub
