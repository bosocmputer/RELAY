# ใบงาน: บอกผู้ใช้ว่าต้องทำอะไรต่อหลังจบแต่ละขั้น (20261102-guided-next-step)
- **ปัญหา (จากการทดสอบจริง):** จบขั้นที่ 1 @po แล้วผู้ใช้ไม่รู้ว่าต้องพิมพ์ `/exit` • หลังออกต้องกลับหน้าหลักแล้วเลือกขั้นถัดไปเองทุกครั้ง
- **สาเหตุ:** คำแนะนำ `/exit` แสดงก่อนเปิด CLI แล้วถูกหน้าจอของ AI บังทันที • จบขั้นแล้วไม่มีการเสนอขั้นถัดไป
- **ข้อจำกัด:** ไม่เพิ่มการเรียก AI • ไม่ข้ามขั้นโดยไม่ถาม • ไม่เปลี่ยนลูปอัตโนมัติ

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- [ ] prompt ของขั้นแบบโต้ตอบ (1–4, งานด่วน, ตำแหน่งเพิ่มเติม) สั่งให้ AI ปิดท้ายด้วยข้อความบอกให้พิมพ์ `/exit` เพื่อกลับ RELAY
- [ ] กลับจาก CLI แล้ว ถ้าได้ผลของขั้นนั้น ➔ เสนอเมนูขั้นถัดไปทันที: 1 ➔ [2]/[a] • 2 ➔ [3]/[a] • 3 ➔ [4] • 4 PASS ➔ [5], FAIL ➔ [3] • งานด่วน ➔ [4]/[5] • ทุกเมนูมี [b] กลับหน้าหลัก
- [ ] ยังไม่ได้ผลของขั้นนั้น ➔ บอกตรงๆ ว่ายังไม่พบไฟล์ไหน และกดอะไรเพื่อทำต่อ (ไม่แสดงเมนูไปขั้นถัดไป)
- [ ] stdin หมด / ไม่ใช่ TTY ➔ ไม่ไปขั้นถัดไปเอง
- [ ] มีชุดทดสอบ และชุดทดสอบเดิมผ่านทั้งหมด
