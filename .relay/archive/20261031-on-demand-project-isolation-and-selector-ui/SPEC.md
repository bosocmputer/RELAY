# ใบกำหนดความต้องการ (SPEC.md — 20261031-on-demand-project-isolation-and-selector-ui)

## 1. เป้าหมายและขอบเขตของงาน (Goal & Scope)
1. **การแยกขอบเขตการทำงานรายโปรเจกต์แบบเปิด-ปิดตามต้องการ (`On-Demand Per-Project Isolation` ใน `templates/GLOBAL_AGENTS.md`):**
   - ปรับกฎส่วนกลางใน `templates/GLOBAL_AGENTS.md` ให้บังคับใช้กระบวนการทีม 4 ขั้นตอน (`SPEC.md` + `Git Worktree`) **เฉพาะในโปรเจกต์ที่มีโฟลเดอร์ `.relay/` หรือเมื่อถูกเรียกผ่านคำสั่ง `relay` (`@po`, `@arch`, `@dev`, `@qa`) เท่านั้น**
   - หากผู้ใช้เปิด CLI (`agy`, `claude`, `codex`) ทำงานในโปรเจกต์ทั่วไปที่ไม่มี `.relay/` (หรือสั่งงานปกติโดยไม่ได้เรียกบทบาททีม) ให้ทำงานตามปกติทันทีโดยไม่บังคับสร้าง `SPEC.md` หรือ `Git Worktree` (คงไว้เฉพาะกฎห้ามแตะไฟล์ความลับ `.env*`/`*.key` และมาตรฐานไอคอน)
2. **การออกแบบหน้าเลือกโปรเจกต์ใหม่ให้จำแนกง่ายในพริบตา (`select_or_create_project_dir` ใน `relay.sh`):**
   - จัดกลุ่มและเรียงโปรเจกต์ที่ติดตั้ง `.relay/` แล้วไว้ด้านบนสุดเสมอ ไม่ให้ถูกตัดตกขอบโดยโฟลเดอร์ทั่วไป
   - แสดงป้ายสถานะสีไว้ด้านหน้าบรรทัดในคอลัมน์ที่ตรงกัน: **`● [RELAY]`** (สีเขียว — พร้อมแสดงชื่อ Task ปัจจุบันหรือสถานะพร้อมใช้งาน) แยกจาก **`○ [ทั่วไป]`** (สีเทา — ยังไม่ได้ติดตั้ง `.relay/`)
   - ปรับข้อความเมนูและแถบช่วยเหลือด้านล่างเพื่อลดปัญหาสระลอยใน macOS Terminal.app
3. **การอัปเดตเอกสารที่เกี่ยวข้องทั้งหมด (`README.md`, `docs/`):**
   - อัปเดต `README.md`, `docs/USE_CASES_NEW_AND_EXISTING.md`, และ `docs/ARCHITECTURE_DEEP_DIVE.md` ให้อธิบายหลักการ On-Demand Per-Project Isolation และหน้าเลือกโปรเจกต์แบบใหม่โดยไม่ Over-claim

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
- [ ] **AC-1 (`GLOBAL_AGENTS.md` On-Demand Isolation):** `templates/GLOBAL_AGENTS.md` (และ `~/.agents/GLOBAL_AGENTS.md`) ระบุเงื่อนไขชัดเจนว่ากระบวนการ `.relay/` ทำงานเฉพาะโปรเจกต์ที่มี `.relay/` หรือเมื่อเรียกผ่าน `relay` เท่านั้น ไม่รบกวนโปรเจกต์ทั่วไป
- [ ] **AC-2 (`select_or_create_project_dir` UI):** หน้าเลือกโปรเจกต์เรียงโปรเจกต์ `● [RELAY]` ขึ้นก่อนเสมอ แสดงป้าย `● [RELAY]` / `○ [ทั่วไป]` ด้านหน้าชื่อโปรเจกต์ในคอลัมน์ที่ตรงกัน พร้อมแสดงชื่อ Task ปัจจุบันของแต่ละโปรเจกต์
- [ ] **AC-3 (Documentation & Tests):** อัปเดต `README.md` และ `docs/` ครบถ้วน และผ่านชุดทดสอบอัตโนมัติทุกชุด 100%
