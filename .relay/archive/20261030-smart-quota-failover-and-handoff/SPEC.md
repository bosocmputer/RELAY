# ระบบสลับค่าย/กระเป๋าโควต้าเมื่อโควต้าต่ำ และการส่งต่อบริบทไฟล์ค้างอัตโนมัติ (`20261030-smart-quota-failover-and-handoff`)

## 1. เป้าหมาย (Objective)
แก้ปัญหาเมื่อโควต้าของค่ายใดค่ายหนึ่ง (เช่น `@dev`) ลดต่ำกว่าเกณฑ์ (`< 20%`) หรือหมดกลางคันระหว่างทำงาน โดยให้สลับกระเป๋าโควต้า/ค่ายในคลิกเดียว (หรือสลับอัตโนมัติเมื่อเปิดโหมด `Auto-Failover`) พร้อมแนบสรุปรายชื่อไฟล์ที่ทำค้างไว้ใน `Git Worktree` (`0 Token`) ให้ AI ตัวใหม่รับไม้ต่อได้ทันที

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
- [ ] AC-1: `get_worktree_handoff_context_note` สรุปรายชื่อไฟล์ที่แก้ไขค้างไว้ (`git status`/`git diff --stat`) และ commit ก่อนหน้าใน Worktree ด้วยสคริปต์ระบบ (`0 Token`) แนบเข้าสู่ Prompt ของ `@dev` อัตโนมัติเมื่อมีงานทำค้างอยู่
- [ ] AC-2: `list_quota_failover_candidates` จัดอันดับค่าย/กระเป๋าโควต้าที่พร้อมใช้งานในเครื่องเรียงตามเปอร์เซ็นต์โควต้าคงเหลือสูงสุด (`agy Gemini`, `agy Claude/GPT`, `codex`, `claude`)
- [ ] AC-3: เมื่อโควต้า `< 20%` ใน `check_role_quota_safe` (หรือเมื่อเปิดโหมด `Auto-Failover` / เมนูถามหน้าจอ) รองรับการสลับค่าย/โมเดลในปุ่มเดียว การฝืนรันต่อด้วยโมเดลเดิม หรือการสลับอัตโนมัติไปยังกระเป๋าที่โควต้า `>= 50%`
- [ ] AC-4: เมื่อ CLI จบด้วยข้อผิดพลาดกลางคันในลูปอัตโนมัติหรือโหมดกดมือ รองรับการสลับค่ายเพื่อรับไม้ต่อใน Worktree เดิมทันที และผ่านชุดทดสอบอัตโนมัติครบทุกข้อ
