# ใบงาน: commit แรกต้องรวมโค้ดเดิมของโปรเจกต์ (20261102-first-commit-keeps-code)
- **ปัญหา:** โปรเจกต์เดิมที่ยังไม่มี git ➔ `ensure_git_repo_ready_for_worktree` สร้าง commit แรกแบบว่าง ➔ Worktree ของ `@dev` แยกจาก commit ว่าง จึงไม่เห็นโค้ดเดิม
- **ขอบเขต:** แก้เฉพาะกรณียังไม่มี commit แรก (repo ที่มี commit แล้วไม่เปลี่ยนพฤติกรรม)

## เกณฑ์ตรวจรับ (Acceptance Criteria)
- [ ] ยังไม่มี commit แรกและมีไฟล์อยู่ ➔ แสดงจำนวนไฟล์ แล้วถามก่อน commit (ไม่ commit เงียบๆ)
- [ ] ยืนยัน ➔ commit แรกมีไฟล์เดิม แต่ไม่รวม `.relay/` และไฟล์ความลับ (`.env*`, `*.key`, `*.pem`, `*.sqlite*`, `*.db`) และรวม `.gitignore` ที่มี `.relay/worktrees/`
- [ ] ยกเลิก หรือ stdin หมด ➔ ไม่สร้าง commit และไม่สร้าง Worktree พร้อมบอกวิธีทำเอง
- [ ] โฟลเดอร์ว่าง ➔ สร้าง commit ว่างเหมือนเดิม
- [ ] มีชุดทดสอบครอบคลุมทั้ง 3 กรณี และชุดทดสอบเดิมผ่านทั้งหมด
