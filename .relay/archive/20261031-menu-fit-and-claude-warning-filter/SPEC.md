# ใบงานแก้เมนูวาดซ้อนเมื่อจอแคบ + ตัวกรองคำเตือนของ claude (20261031-menu-fit-and-claude-warning-filter)
- **ที่มา:** ทดลองใช้ `relay` จริงใน Terminal ของแอป: (1) กด ↑/↓ แล้วบรรทัด `[1] @po` ซ้ำ 4 ครั้ง — จำลองซ้ำได้เมื่อ Terminal ไม่ทำตาม `ESC[?7l` และข้อความเมนูกว้างกว่าจอ (2) `[t]` แสดงคำเตือน `Permission allow rule (../../.claude/settings.json)` เต็มจอ เพราะตัวกรองจับเฉพาะพาธ `(.claude/settings.json)`
- **ข้อจำกัด:** คง Bash + Python 3, `/bin/bash` 3.2, ไม่เรียก python ทุกครั้งที่วาดเมนู

- [ ] ข้อความเมนูที่กว้างกว่าจอถูกตัดให้พอดีพร้อม `…` ก่อนพิมพ์ (ไม่พึ่ง `ESC[?7l`) • กด ↑/↓ บนจอแคบแล้วเมนูไม่เลื่อน/ไม่ซ้อน
- [ ] ตัดข้อความภาษาไทยไม่ทำให้ตัวอักษรเสีย แม้ locale ของ shell เป็น `C`
- [ ] แถบ Shortcuts มีแบบย่อเมื่อจอแคบกว่า 80 คอลัมน์ โดยจำนวนบรรทัดเท่าเดิม
- [ ] คำเตือน `Permission allow rule (<พาธใดก็ได้>)` ของ claude ถูกกรองทั้งใน `[t]` และตอนเปิด CLI ของแต่ละขั้นตอน
