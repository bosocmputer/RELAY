# RELAY (`.relay/`): มาตรฐานสถาปัตยกรรมการทำงานร่วมกับตัวแทน AI หลายค่ายผ่านหน้าจอควบคุมกลางและเอกสารกำหนดข้อตกลง (v1.0 Official Edition)

**ระบบจัดการกระบวนการพัฒนาซอฟต์แวร์ร่วมกับตัวแทน AI (`Gemini`, `Claude`, `Codex`) ผ่านหน้าจอควบคุม Terminal กลาง (`relay`) และเอกสารส่งมอบงานในโฟลเดอร์ `.relay/`**  
*รองรับทั้งระบบปฏิบัติการ **Windows** และ **macOS** • ควบคุมทุกขั้นตอนในหน้าต่าง Terminal เดียว • กำหนดค่าย AI ประจำตำแหน่งได้อิสระ • ลดการใช้ Token 85–90% • ปลอดภัยตามเงื่อนไขการใช้งานแพ็กเกจรายเดือน (Subscription) 100%*

## 1. ที่มาและหลักการทำงานของระบบ `RELAY`

ในการพัฒนาซอฟต์แวร์ด้วยตัวแทน AI (AI Coding Agents) การสั่งงานต่อเนื่องในหน้าต่างสนทนาเดียวเป็นเวลานาน หรือการต้องเปิดสลับหน้าต่างโปรแกรมหลายค่ายด้วยตนเอง มักก่อให้เกิดปัญหาสำคัญ 3 ประการ:
1. **ความคลาดเคลื่อนของผลลัพธ์เมื่อบริบทยาวเกินไป (Context Rot):** เมื่อประวัติการสนทนาสะสมมากขึ้น โมเดลภาษาจะเริ่มสับสนระหว่างข้อกำหนดเริ่มต้นกับการแก้ไขเฉพาะหน้า
2. **การสิ้นเปลืองโควตาการประมวลผล (Token Explosion):** ทุกข้อความใหม่ที่ส่งเข้าไปในหน้าต่างสนทนาเดิม ระบบจะต้องส่งประวัติการสนทนาทั้งหมดกลับไปประมวลผลซ้ำทุกครั้ง ทำให้โควตาของแพ็กเกจรายเดือนหมดลงอย่างรวดเร็ว
3. **ความยุ่งยากในการสลับเครื่องมือและความเสี่ยงด้านบัญชี:** การต้องคอยเปิด-ปิดและคัดลอกข้อความข้ามไปมาระหว่าง CLI หลายค่ายด้วยตนเองทำให้เสียเวลา ในขณะที่การใช้บอทเถื่อนยิงคำสั่งอัตโนมัติเบื้องหลัง (Headless Loop) ก็มีความเสี่ยงถูกระงับบัญชี

### แนวทางแก้ไขของระบบ `RELAY`: หน้าจอควบคุมกลาง (`relay` Hub) + เอกสารส่งมอบงาน 4 ขั้นตอน (`.relay/`)
1. **กำหนดค่าย AI ประจำตำแหน่งได้ตามต้องการ (`Role-to-Provider Mapping`):** ผู้ใช้สามารถตั้งค่าได้ว่าต้องการให้ขั้นตอนที่ 1 (`@po`), ขั้นตอนที่ 2 (`@arch/@pm`), ขั้นตอนที่ 3 (`@dev`), และขั้นตอนที่ 4 (`@qa/@sec`) เรียกใช้ AI ของค่ายใด (`claude`, `codex`, หรือ `gemini`) ทั้งแบบค่าเริ่มต้นทั้งเครื่อง (`~/.agents/relay-roles.conf`) หรือกำหนดแยกเฉพาะโครงการ (`.relay/roles.conf`)
2. **สั่งงานผ่านหน้าจอ Terminal กลางที่เดียว (`relay` Central Terminal Hub):** เพียงพิมพ์คำสั่ง **`relay`** ในโฟลเดอร์โครงการ หน้าจอควบคุมกลางจะแสดงสถานะใบงานและให้คุณกดเลือกขั้นตอนที่ 1 ถึง 5 ได้ในหน้าต่างเดียว โดยระบบจะเรียก Interactive CLI ของค่ายที่คุณตั้งค่าไว้ขึ้นมาทำงานพร้อมส่งบริบทจากโฟลเดอร์ `.relay/` ให้โดยอัตโนมัติ

| :--- | :--- | :--- |
| **1. หน้าจอควบคุมกลางและการตั้งค่าค่าย AI** | คำสั่ง **`relay`** (`relay.sh` / `relay.ps1`) + ไฟล์ **`relay-roles.conf`** | ศูนย์กลางการสั่งงานในหน้าต่าง Terminal เดียว ทำหน้าที่จับคู่ตำแหน่ง (`@po`, `@arch`, `@dev`, `@qa`) เข้ากับค่าย AI ที่กำหนด และส่งต่อไฟล์เอกสารให้แต่ละขั้นตอนโดยอัตโนมัติ |

## 3. การติดตั้งระบบตั้งแต่เริ่มต้น (รองรับทั้ง Windows และ macOS)

> 📖 **สำหรับผู้เริ่มต้นที่ยังไม่มีเครื่องมือพื้นฐานในเครื่อง:** สามารถศึกษาขั้นตอนการติดตั้งแบบละเอียดทีละขั้นตอนได้ที่เอกสาร **[`docs/INSTALL_ZERO_TO_HERO.md`](./docs/INSTALL_ZERO_TO_HERO.md)**

### ขั้นตอนที่ 3.1: ติดตั้งโปรแกรมพื้นฐาน (Git, Node.js, Obsidian) และ Official CLI

#### 🍎 สำหรับระบบปฏิบัติการ macOS (รันใน `Terminal`)
```bash
# 1. ติดตั้ง Git, Node.js, pnpm และโปรแกรม Obsidian ผ่าน Homebrew
brew install git node pnpm
brew install --cask obsidian

# 2. ติดตั้ง Official CLI ของผู้ให้บริการที่คุณมีแพ็กเกจรายเดือน (เลือกค่ายที่ใช้งาน หรือติดตั้งทั้งหมด)
npm install -g @anthropic-ai/claude-code @openai/codex @google/gemini-cli
```

#### 🪟 สำหรับระบบปฏิบัติการ Windows (คลิกขวาเปิด `PowerShell` แบบ Run as Administrator)
```powershell
# 1. ติดตั้ง Git, Node.js (LTS) และโปรแกรม Obsidian ผ่าน winget
winget install --id Git.Git -e --source winget
winget install --id OpenJS.NodeJS.LTS -e --source winget
winget install --id Obsidian.Obsidian -e --source winget
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force

# 2. ปิดหน้าต่าง PowerShell แล้วเปิดใหม่ 1 ครั้ง จากนั้นติดตั้ง Official CLI
npm install -g @anthropic-ai/claude-code @openai/codex @google/gemini-cli
```
*(หลังจากติดตั้งเสร็จสิ้น ให้พิมพ์คำสั่ง `claude`, `codex` หรือ `gemini` เพื่อเข้าสู่ระบบตามสิทธิ์บัญชีรายเดือนของคุณ 1 ครั้ง)*

### ขั้นตอนที่ 3.2: ติดตั้งระบบ `RELAY` และคำสั่งหน้าจอควบคุมกลาง (`relay`)

สคริปต์ติดตั้งจะทำการสร้างโฟลเดอร์ส่วนกลาง (`~/.agents/` บน macOS หรือ `%USERPROFILE%\.agents\` บน Windows) ติดตั้งคำสั่ง **`relay`** เข้าสู่ `PATH` ของระบบ ทำให้คุณสามารถพิมพ์คำว่า **`relay`** ได้จากทุกโฟลเดอร์โครงการในเครื่องทันที

#### 🍎 คำสั่งติดตั้งบน macOS / Linux:
```bash
git clone https://github.com/bosocmputer/RELAY.git
cd RELAY
chmod +x setup-mac.sh relay.sh relay-init.sh relay-skills.sh
./setup-mac.sh
source ~/.zshrc
./relay-skills.sh install
```

#### 🪟 คำสั่งติดตั้งบน Windows (PowerShell):
```powershell
git clone https://github.com/bosocmputer/RELAY.git
cd RELAY
.\setup-win.ps1
.\relay-skills.ps1 install
```

## 4. การตั้งค่าจับคู่ตำแหน่งกับค่าย AI และการใช้งานหน้าจอ Terminal กลาง (`relay`)

หลังติดตั้งเสร็จสิ้น คุณสามารถเปิดใช้งานและตั้งค่าระบบผ่านหน้าต่าง Terminal เดียวได้ดังนี้:

### 4.1 การกำหนดว่าแต่ละตำแหน่งจะใช้ AI ค่ายใด (`relay config`)
รันคำสั่ง `relay config` (หรือกดปุ่ม `c` ในหน้าจอหลักของ `relay`) เพื่อกำหนดค่าย AI (`claude`, `codex`, หรือ `gemini`) ให้กับแต่ละขั้นตอน:
- **ขั้นตอนที่ 1 (`@po` — วิเคราะห์ความต้องการ):** ค่าเริ่มต้นคือ `gemini` (สามารถเปลี่ยนเป็น `claude` หรือ `codex` ได้)
- **ขั้นตอนที่ 2 (`@arch & @pm` — ออกแบบและวางแผน):** ค่าเริ่มต้นคือ `claude`
- **ขั้นตอนที่ 3 (`@dev` — พัฒนาโค้ดใน Git Worktree):** ค่าเริ่มต้นคือ `claude`
- **ขั้นตอนที่ 4 (`@qa & @sec` — ตรวจสอบคุณภาพและความปลอดภัย):** ค่าเริ่มต้นคือ `codex`

*(คุณสามารถเลือกบันทึกเป็นค่าเริ่มต้นส่วนกลางของเครื่อง `~/.agents/relay-roles.conf` หรือบันทึกแยกเฉพาะโครงการที่ `.relay/roles.conf` ได้ตามต้องการ)*

### 4.2 การเปิดหน้าจอควบคุมกลาง (`relay`)
เมื่ออยู่ในโฟลเดอร์โครงการใดก็ตาม ให้พิมพ์คำสั่งเดียวใน Terminal / PowerShell:
```bash
relay
```
หน้าจอควบคุมกลางของ `RELAY` จะแสดงผลดังนี้:
```text

======================================================================

📌 สถานะโครงการ  : ✅ พร้อมใช้งาน (.relay/PROJECT_STATE.md)

   • ขั้นตอนที่ 1 (@po)       ➔ ค่าย: gemini | โมเดล: default (gemini-2.5-pro) | ✅ พร้อมใช้งาน

เลือกคำสั่งการทำงาน (พิมพ์หมายเลขหรือตัวอักษรแล้วกด Enter ในหน้าต่างนี้ได้เลย):
  [1] เริ่มขั้นตอนที่ 1 (@po)        — วิเคราะห์ความต้องการและสร้าง SPEC.md
  [2] เริ่มขั้นตอนที่ 2 (@arch/@pm)  — อ่าน SPEC.md แล้วสร้าง ARCH.md & PLAN.md

  [q] ออกจากโปรแกรม
```

### 4.3 การทดสอบความพร้อมของตัวแทน AI แต่ละตำแหน่ง (`[t]` หรือ `relay test`)
หลังจากตั้งค่าค่าย AI และโมเดลเสร็จสิ้น คุณสามารถกดปุ่ม **`t`** ในหน้าจอหลัก (หรือพิมพ์คำสั่ง `relay test` หรือเลือกทดสอบทันทีหลังตั้งค่าในเมนู `[c]`) เพื่อตรวจสอบความพร้อมทั้ง 2 ระดับ:
1. **ตรวจสอบทักษะและกฎส่วนกลางในเครื่อง (Local Check):** แสดงรายการทักษะ (`Skills`) ประจำตำแหน่งของ `@po`, `@arch/@pm`, `@dev`, และ `@qa/@sec` พร้อมสถานะการเชื่อมต่อไฟล์กฎส่วนกลาง (`GLOBAL_AGENTS.md`)
2. **ยิงคำสั่งทดสอบให้ AI แต่ละตำแหน่งรายงานตัวจริง (Live Agent Handshake):** ส่งคำสั่งทดสอบไปยัง CLI และ Model ที่ตั้งไว้ของแต่ละตำแหน่ง เพื่อให้ตัวแทน AI ตอบกลับมารายงานบทบาท หน้าที่รับผิดชอบ และรายชื่อทักษะของตนเองว่าพร้อมปฏิบัติงาน 100%

## 5. การติดตั้งและการใช้งานร่วมกับโปรแกรม Obsidian

### 5.1 เหตุผลที่แนะนำให้ติดตั้งโปรแกรม Obsidian ควบคู่กับหน้าจอ `relay`
ในขณะที่คุณใช้หน้าต่าง Terminal เดียวในการรันคำสั่ง `relay` การเปิดโปรแกรม **Obsidian (ใช้งานฟรี 100%)** ไว้ด้านข้างจะช่วยให้คุณมีหน้าจอสำหรับอ่านและแก้ไขเอกสาร `PROJECT_STATE.md`, `SPEC.md`, `ARCH.md`, `PLAN.md` และดูแผนภาพสถาปัตยกรรม (Mermaid) ได้แบบเรียลไทม์
- **ลิงก์ดาวน์โหลดโดยตรง:** [https://obsidian.md](https://obsidian.md)

### 5.2 วิธีเชื่อมต่อโฟลเดอร์ `.relay/` เข้ากับโปรแกรม Obsidian
1. เปิดโปรแกรม **Obsidian** ➔ คลิกปุ่ม **"Open folder as vault"** (เปิดโฟลเดอร์เป็นคลังข้อมูล)
2. เลือกเข้าไปที่โฟลเดอร์ **`.relay`** ภายในโครงการของคุณ (เช่น `my-project/.relay`) แล้วกด **Open**
   *(สำหรับผู้ใช้ macOS: หากไม่เห็นโฟลเดอร์ `.relay` ในหน้าต่างเลือกไฟล์ ให้กดปุ่มลัด `Command (⌘) + Shift + .` เพื่อแสดงโฟลเดอร์ที่ขึ้นต้นด้วยจุด)*

## 6. วิธีการนำระบบ `RELAY` ไปใช้งานจริง (2 กรณีศึกษาหลัก)

> 📖 ศึกษารายละเอียดเชิงลึกเพิ่มเติมได้ที่ **[`docs/USE_CASES_NEW_AND_EXISTING.md`](./docs/USE_CASES_NEW_AND_EXISTING.md)**

### กรณีศึกษาที่ 1: การเริ่มต้นโครงการใหม่ตั้งแต่ศูนย์ (Greenfield Project — ติดตั้ง `RELAY` ก่อนเริ่มพัฒนาซอฟต์แวร์)
1. สร้างโฟลเดอร์โครงการใหม่และเริ่มต้นระบบ Git:
   ```bash
   mkdir my-new-app && cd my-new-app
   git init -b main
   ```
2. พิมพ์คำสั่ง **`relay`** เพื่อเปิดหน้าจอควบคุมกลาง:
   - กด **`i`** ➔ เลือก **`[1] โครงการใหม่ตั้งแต่ศูนย์`** เพื่อสร้างโครงสร้าง `.relay/`
   - กด **`1`** เพื่อเข้าสู่ **ขั้นตอนที่ 1 (`@po`)** ระบบจะเปิด CLI ของค่ายที่คุณตั้งไว้ (เช่น `gemini`) ขึ้นมาซักถามความต้องการและสร้างไฟล์ `SPEC.md` เมื่อเสร็จแล้วให้พิมพ์ `/exit` เพื่อกลับสู่หน้าจอกลางของ `relay`
   - กด **`2`** เพื่อเข้าสู่ **ขั้นตอนที่ 2 (`@arch & @pm`)** สร้างไฟล์ `ARCH.md` และ `PLAN.md`
   - กด **`3`** เพื่อเข้าสู่ **ขั้นตอนที่ 3 (`@dev`)** ระบบจะสร้าง `Git Worktree` แยกกิ่งให้อัตโนมัติและเปิด CLI ของ `@dev` (เช่น `claude`) เพื่อเขียนโค้ดและชุดทดสอบ
   - กด **`4`** เพื่อเข้าสู่ **ขั้นตอนที่ 4 (`@qa & @sec`)** เพื่อรันชุดทดสอบ สแกนความปลอดภัย ทดสอบผ่าน Playwright MCP และสรุป `QA_REPORT.md`
   - กด **`5`** เพื่อผสานโค้ด (Merge) เข้าสู่กิ่ง `main` และย้ายใบงานเก็บเข้าสู่ `.relay/archive/` อัตโนมัติ

### กรณีศึกษาที่ 2: การนำ `RELAY` ไปใช้กับโครงการเดิมที่มีอยู่แล้ว (Brownfield / Existing Project)
1. เปิด Terminal เข้าไปยังโฟลเดอร์โครงการเดิมของคุณ (`cd /path/to/existing-project`) แล้วพิมพ์คำสั่ง **`relay`**
2. ในหน้าจอควบคุมกลางของ `relay` ให้กดปุ่ม **`i`** ➔ เลือก **`[2] โครงการเดิมที่มีโค้ดอยู่แล้ว (สแกนสร้าง PROJECT_STATE.md)`**:
   - ระบบจะสร้างโฟลเดอร์ `.relay/` และเปิด CLI ของ `@arch` ขึ้นมาพร้อมส่งคำสั่งให้สแกนโครงสร้างโค้ดเดิม ฐานข้อมูล และ API เพื่อสรุปเป็นไฟล์ **`.relay/PROJECT_STATE.md`** (ความยาวไม่เกิน 2 หน้า) เพียงครั้งเดียว
   - เมื่อสร้าง `PROJECT_STATE.md` เสร็จแล้ว ให้พิมพ์ `/exit` เพื่อกลับสู่หน้าจอกลางของ `relay`
3. เริ่มต้นเพิ่มฟีเจอร์ใหม่หรือแก้ไขข้อผิดพลาดในโครงการเดิมได้ทันทีโดยกด **`1`** (`@po`) ➔ **`2`** (`@arch/@pm`) ➔ **`3`** (`@dev` ในกิ่งแยกโดยไม่กระทบโค้ดเดิม) ➔ **`4`** (`@qa/@sec`) ➔ และ **`5`** (`Merge & Archive`)

## 7. ระบบจัดการ การอัปเดต และการเพิ่มชุดทักษะ (`relay-skills`)

คุณสามารถกดปุ่ม **`s`** ในหน้าจอหลักของ `relay` (หรือรันคำสั่ง `relay-skills` โดยตรง) เพื่ออัปเดตทักษะเดิมตามผู้พัฒนาต้นทางบน GitHub หรือเพิ่มทักษะใหม่เข้าสู่ระบบ:

| การดำเนินการ | คำสั่งผ่านหน้าจอ `relay` | คำสั่งตรงบน macOS / Linux | คำสั่งตรงบน Windows (`PowerShell`) |
| :--- | :--- | :--- | :--- |
| **1. ติดตั้งชุดทักษะมาตรฐาน** | กด `s` ➔ เลือก `2` | `./relay-skills.sh install` | `.\relay-skills.ps1 install` |
| **2. อัปเดตทักษะเป็นเวอร์ชันล่าสุด** | กด `s` ➔ เลือก `3` | `./relay-skills.sh update` | `.\relay-skills.ps1 update` |
| **3. เพิ่มทักษะใหม่เข้าสู่คลัง** | กด `s` ➔ เลือก `4` | `./relay-skills.sh add <repo_url> [skill]` | `.\relay-skills.ps1 add <repo_url> [skill]` |
| **4. แสดงรายการทักษะทั้งหมด** | กด `s` ➔ เลือก `1` | `./relay-skills.sh list` | `.\relay-skills.ps1 list` |
