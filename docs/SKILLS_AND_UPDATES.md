# 🧰 คู่มือการจัดการ อัปเดต และเพิ่ม Skills ใหม่ (`SKILLS_AND_UPDATES.md`)

จุดเด่นสำคัญของ `RELAY` คือ **ระบบซองทักษะแยกตามบทบาท (Modular Skill Packs)** ที่ติดตั้งไว้ที่ส่วนกลางของเครื่อง (`~/.agents/skills/` บน Mac หรือ `%USERPROFILE%\.agents\skills\` บน Windows) และสามารถ **อัปเดตตามผู้พัฒนาต้นทางบน GitHub** หรือ **เพิ่มสกิลใหม่เข้าคลัง** ได้ตลอดเวลา

---

## 1. วิธีอัปเดต Skills ทั้งหมดให้เป็นเวอร์ชันล่าสุดตามผู้พัฒนาต้นทาง

เมื่อผู้พัฒนาสกิลต้นทาง (เช่น ทีม Vercel, Supabase, Trail of Bits, Semgrep, หรือ Obra) อัปเดตความรู้หรือแนวทางเขียนโค้ดใหม่ๆ บน GitHub ของพวกเขา คุณสามารถดึงอัปเดตทั้งหมดลงเครื่องได้ด้วยคำสั่งเดียว:

### 🍎 บนเครื่อง Mac / Linux:
```bash
./relay-skills.sh update
```

### 🪟 บนเครื่อง Windows (PowerShell):
```powershell
.\relay-skills.ps1 update
```
*(สคริปต์จะอ่านรายชื่อ Repo ทั้งหมดจากไฟล์ [`skills-manifest.txt`](../skills-manifest.txt) แล้วดึงเวอร์ชันล่าสุดจาก GitHub มาอัปเดตทับในคลังกลางของเครื่องให้อัตโนมัติ)*

---

## 2. วิธีเพิ่ม Skill ใหม่ที่คุณไปเจอมาจาก GitHub เข้าสู่ระบบ `RELAY`

หากคุณไปเจอ Repo สกิลเจ๋งๆ บน GitHub (เช่น สกิลทำแอนิเมชัน, สกิลเขียน Go/Rust, หรือสกิลวิเคราะห์ข้อมูล) คุณสามารถสั่งเพิ่มเข้าเครื่องพร้อมบันทึกเข้าคลังรายการอัปเดตอัตโนมัติได้ทันที:

### 🍎 บนเครื่อง Mac / Linux:
```bash
# กรณีต้องการลงเฉพาะสกิลที่ระบุใน Repo
./relay-skills.sh add https://github.com/owner/repo-name ชื่อสกิล "[ไม้ 3 @dev] คำอธิบายสกิล"

# กรณีต้องการลงทั้ง Repo
./relay-skills.sh add https://github.com/owner/repo-name
```

### 🪟 บนเครื่อง Windows (PowerShell):
```powershell
.\relay-skills.ps1 add https://github.com/owner/repo-name ชื่อสกิล "[ไม้ 3 @dev] คำอธิบายสกิล"
```

**เกิดอะไรขึ้นเมื่อคุณรันคำสั่ง `add`?**
1. ระบบจะรัน `npx skills add ... -g` เพื่อติดตั้งสกิลนั้นเข้าสู่คลังกลางของเครื่องทันที
2. ระบบจะบันทึกชื่อ Repo นั้นต่อท้ายลงในไฟล์ [`skills-manifest.txt`](../skills-manifest.txt) อัตโนมัติ ทำให้ครั้งต่อไปที่คุณรันคำสั่ง `update` สกิลใหม่ที่คุณเพิ่มเข้ามาก็จะได้รับการอัปเดตไปด้วยเสมอ!

---

## 3. วิธีตรวจสอบรายการ Skills ทั้งหมดที่มีในเครื่อง (`list`)

```bash
# บน Mac / Linux
./relay-skills.sh list

# บน Windows PowerShell
.\relay-skills.ps1 list
```

---

## 4. วิธีเขียน `SKILL.md` ของคุณเอง (สำหรับงานเฉพาะทางของบริษัทคุณ)

หากคุณต้องการสร้างกฎหรือสูตรลับเฉพาะของทีมคุณเอง (เช่น มาตรฐานการตั้งชื่อตารางของบริษัท หรือขั้นตอนการเทสต์ระบบภายใน) คุณสามารถสร้างโฟลเดอร์สกิลใหม่ได้ง่ายๆ ดังนี้:

1. สร้างโฟลเดอร์ใหม่ใน `~/.agents/skills/<ชื่อสกิลของคุณ>/`
2. สร้างไฟล์ชื่อ `SKILL.md` ข้างใน โดยใช้โครงสร้างมาตรฐาน (ความยาวไม่ควรเกิน 150 บรรทัดเพื่อประหยัด Token):

```markdown
---
name: my-company-standard
description: มาตรฐานการเขียน API และการตั้งชื่อตัวแปรของบริษัทเรา
---

# ขั้นตอนปฏิบัติเมื่อต้องสร้าง API ใหม่
1. ใช้รูปแบบ URL เป็น `/api/v1/<resource>` เสมอ
2. ทุก Response ต้องคืนค่าในรูปแบบ `{ success: boolean, data: any, error: string | null }`
3. ห้ามลืมเขียน Unit Test ตรวจสอบกรณี `400 Bad Request` และ `401 Unauthorized` ทุกครั้ง
```
3. เพิ่มชื่อสกิล `my-company-standard` เข้าไปในบทบาทที่ต้องการในไฟล์ `~/.agents/GLOBAL_AGENTS.md` (หรือในไฟล์ `AGENTS.md` เฉพาะโปรเจกต์นั้น) ได้ทันที!
